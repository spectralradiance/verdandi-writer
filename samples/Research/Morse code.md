# Morse code

| Letter | Code |
| --- | --- |
| S | ··· |
| K | −·− |
| R | ·−· |
| O | −−− |

The beacon's call sign in the novel is **SKR**: `··· −·− ·−·`.

Radio beacons repeated their call sign so ships with direction-finding sets could take a bearing. An operator's style of sending was called their *fist*; experienced operators could recognise each other by it.

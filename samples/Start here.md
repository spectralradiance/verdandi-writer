# Start here

This folder is a sample workspace for Verdandi Writer. Copy it before you try things, or run `scripts/dev.ps1 -Samples`, which opens a copy.

- **Salt and Signal**: a novel in progress, as a document folder. Each chapter is a file with text and four layers: *notes* (anchored to paragraphs), *outline* (a list), *research* and *images* (a gallery). Chapters have fields (`status`, `pov`, `tags`), and the document has three saved views: Outline, Drafting act one, Still ideas.
- **Tidelines**: a short cycle of poems, one section each, with notes.
- **Essays**: two one-file documents with `::: notes` blocks. Opening one turns it into a document folder, with Undo.
- **The Night Sky**, **Winter Notebook**, **Field Journal**: smaller one-file documents.
- **Research**: ordinary Obsidian notes with links between them. They open read-only.
